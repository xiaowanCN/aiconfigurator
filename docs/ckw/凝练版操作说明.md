## 1. 机器锁频
在收集数据之前，确保整个节点没有其他训练、推理业务干涉。然后，需启用节点的持久模式和锁定频率，以确保节点的系统工作正常。
```bash
sudo nvidia-smi -pm 1
sudo nvidia-smi -ac yyy,xxx
```
其中，yyy，xxx频率可以通过nvidia smi-q-i 0查询，请参阅最大时钟部分，yyy是内存频率，xxx是SM频率。参数顺序是内存频率在前，SM 频率在后。
设置频率的脚本：
```bash
#!/bin/bash

# Run nvidia-smi query and extract SM and Memory frequencies from Max Clocks
sm_freq=$(nvidia-smi -q -i 0 | grep -A 4 "Max Clocks" | grep "SM " | grep -o "[0-9]\+ MHz" | grep -o "[0-9]\+")
mem_freq=$(nvidia-smi -q -i 0 | grep -A 4 "Max Clocks" | grep "Memory " | grep -o "[0-9]\+ MHz" | grep -o "[0-9]\+")

# Check if frequencies were successfully extracted
if [ -z "$sm_freq" ] || [ -z "$mem_freq" ]; then
    echo "Error: Could not extract SM or Memory frequency from Max Clocks."
    exit 1
fi

# Generate the command
echo "sudo nvidia-smi -ac $mem_freq,$sm_freq"
```

## 4. AiConfigurator 使用
### 4.1 default模式择优部署配置
执行命令可查看是否采用PD分离部署下的最优配置，其中`当 --ttft 2000 时，--tpot 26 值通过以往“910B4推理性能验收标准：当Batchsize为100，In_seq和Out_seq为256时，性能测试指标e2e_time（s）总时延≤8.75 s，e2e_throughput（tokens/s）≥2895.964（tokens/s） ”得到。`：
```bash
aiconfigurator cli default --model deepseek-ai/DeepSeek-V4-Flash --total-gpus 64 --system b300_sxm --backend vllm \
  --isl 256 --osl 256 --ttft 2000 --tpot 26 --top-n 8
```
通过查看报告中关键字段 `Best Experiment Chosen`，如果是 `agg at *** tokens/s/gpu (agg 1.**x better than disagg)` 则选择 `agg` 配置，反之则选择 `disagg`。

通过查看报告中字段 `agg Top Configurations: (Ranked by tokens/s/gpu)` 下中的多个Rank信息来配置推理时的 `vllm` 配置。

例如某Rank 1的信息为：

| Rank | backend | tokens/s/gpu | tokens/s/user | req/s | TTFT | request_latency | concurrency | total_gpus (used) | replicas | gpus/replica | gpus/worker | parallel | bs |
|------|---------|--------------|---------------|-------|------|-----------------|-------------|-------------------|----------|--------------|-------------|----------|-----|
| 1     | vllm    | 4395.46      | 41.09         | 1103.17 | 291.51 | 6497.61         | 7168 (=224x32) | 64 (64=32x2)      | 32       | 2            | 2 (=1x1x2)  | tp1pp1dp2etp2ep1 | 112 |

则可以采用如下的配置：

```bash
# vllm 0.24.0 版本，单个副本，如果需实现32副本，需配合kubectl进行脚本改写。
CUDA_VISIBLE_DEVICES=0,1 \
HF_HOME=/data/hf \
vllm serve deepseek-ai/DeepSeek-V4-Flash \
  --served-model-name deepseek-v4-flash \
  --host 0.0.0.0 \
  --port 8000 \
  --trust-remote-code \
  --dtype auto \
  --max-model-len 32768 \
  --tensor-parallel-size 1 \
  --pipeline-parallel-size 1 \
  --data-parallel-size 2 \
  --enable-expert-parallel \
  --expert-tensor-parallel-size 2 \
  --expert-parallel-size 1 \
  --max-num-seqs 100 \
  --max-num-batched-tokens 32768 \
  --enable-chunked-prefill \
  --gpu-memory-utilization 0.92 \
  --swap-space 0 \
  --disable-log-requests
```
其中对应了参数关系为：
```text
tp1      -> --tensor-parallel-size 1
pp1      -> --pipeline-parallel-size 1
dp2      -> --data-parallel-size 2
etp2     -> --expert-tensor-parallel-size 2
ep1      -> --expert-parallel-size 1
bs100    -> --max-num-seqs 100
```
